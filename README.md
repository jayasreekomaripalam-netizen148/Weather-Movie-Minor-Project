# Weather & Movie Search App — Minor Project 03

Responsive two-in-one website built with HTML5, CSS3, JavaScript ES6+ modules and public REST APIs.

## Features
- Weather search by city (Open-Meteo geocoding + forecast; no key needed)
- Current temperature, weather description, humidity and wind speed
- Movie search, poster, release year, rating and plot (OMDb API key required)
- Async/await, Fetch, JSON, DOM updates, error handling and responsive UI

## Run in VS Code
1. Extract the folder and open it in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html` and choose **Open with Live Server**.

## Enable movies
1. Get a free OMDb API key: https://www.omdbapi.com/apikey.aspx
2. Open `js/movies.js`.
3. Replace `YOUR_OMDB_API_KEY` with your key.
4. Save and reload the browser.

Weather works without an API key. Movie search requires OMDb's key.
